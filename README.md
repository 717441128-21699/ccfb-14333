# 拓片质量自动评分系统

对拓片自动打出质量分,拆成 **墨色均匀 / 字口清晰 / 纸面平整(纸褶) / 石花干扰** 四个分项,
并在图上标注缺陷位置,辅助"哪些碑需要重拓"的决策。评分不用参考图,而是从单张图的
墨色统计、字口 Sobel 锐度、形态学纸褶/石花分析直接计算。

## 角色与功能

| 角色 | 视图 | 能做什么 |
| --- | --- | --- |
| 老先生 | 评分总览 | 每张拓片综合分 + 四分项,按分排序、颜色分档,一眼挑出好坏 |
| 拓工 | 详情(点击卡片) | 单元热力图 + 缺陷框,标明"墨不匀/字口虚/纸褶/石花"在哪一块、严重度多少 |
| 库管 | 按碑分组 | 同碑多张拓本按质量排序,第一名自动标注为主图 |
| 主任 | 质量统计 | 全库分数段分布、拓工×年份的均分/中位/极差与各分项均值 |
| — | 性能基准 | 自定义尺寸(含 6000×9000)计时,对照 3 秒预算,可切换 CPU/WebGL2 |

## 架构

```
src/
├─ core/                 纯 TypeScript 领域逻辑(无 DOM,可独立测试)
│  ├─ types.ts           领域类型、四项权重/标签/主题色
│  ├─ rng.ts             确定性 PRNG、一维/二维值噪声
│  ├─ imageops.ts        Rec.601、Otsu、盒式模糊、Sobel、形态学 tophat
│  ├─ synthetic.ts       合成拓片:四退化通道独立可控 + 字形/退化种子分离
│  ├─ features.ts        CPU 参考特征管线 → 64×64 单元 CellStats
│  ├─ scorer.ts          四项原始严重度、全图聚合、归一化、缺陷连通域
│  ├─ calibration.ts     校准表生成与单调/Spearman 验证
│  ├─ calibration.generated.ts  自动生成的 s0/s1 归一化常数
│  ├─ dataset.ts         拉丁超立方抽样的合成数据集(同碑字形固定)
│  └─ stats.ts           Spearman、按碑分组、拓工×年份统计、分布
├─ gl/
│  ├─ shaders 内置于 engine.ts  WebGL2 逐像素着色器(亮度/模糊/Sobel/tophat/亮异点)
│  ├─ engine.ts          分块 tile 调度 + readPixels
│  ├─ cpuReduce.ts       回读后的单元归约/连通域(与 CPU 管线同公式)
│  └─ service.ts         自动后端:支持 WebGL2 用 GL,否则降级 CPU
└─ app/                  Vite SPA:四角色视图、热力图、基准页
```

### 两条管线为何数值一致

- **CPU 参考管线**(`features.ts`)逐像素算全部特征,再按 64×64 单元归约;
- **WebGL2 管线**(`engine.ts`)把同样的逐像素公式放进着色器并行计算,
  `readPixels` 后调用 `cpuReduce.ts` 做**完全相同**的单元归约与连通域判据。
- `tests/gl-parity.test.ts` 用 CPU 复现着色器输出,验证两条归约路径 CellStats 一致。

## 四个评分项怎么算

| 分项 | 主信号 | 为什么抗干扰 |
| --- | --- | --- |
| 墨色均匀 | 纯墨区单元间亮度变异系数(低频) | 乘性墨层模型 + 单元间统计,对墨色浓淡(风格)不敏感 |
| 字口清晰 | 强边缘占全部边缘的比例 | 磨损让强边转弱;石花/纸褶多为弱边,不改变强边占比 |
| 纸面平整 | tophat 大尺寸低填充连通域密度 | 纸褶是大而稀疏的线;石花是小而饱满的颗粒,形状门控分离 |
| 石花干扰 | tophat 近圆小颗粒密度(反差归一化) | 与纸褶用尺寸+填充率分开,反差归一化抵消浓淡影响 |

## 合成测试数据

`SyntheticOptions` 暴露五个参数:`inkLevel`(风格,不计质量)、`inkUneven`、`wear`、
`wrinkle`、`stoneFlower`(四个退化通道,0..1)。`referenceScore` 按退化程度给参考分。

- **字形种子与退化种子分离**:同一块碑的多张拓本传同一个 `glyphSeed`,字形固定、
  只有拓制质量变化,与真实拓制场景一致。
- **拉丁超立方抽样**:四个退化通道独立分层 + 独立洗牌,通道间近似零相关,
  避免抽样耦合虚高/虚低相关性。

## 测试

```bash
npm test                 # 全部单元/验收测试
UPDATE_CALIBRATION=1 npx vitest run tests/calibration.test.ts   # 重新生成校准表
```

关键验收指标(均在 `tests/` 中断言):

- 综合分与专家参考分 **Spearman ≈ 0.96**,四个分项均 **≥ 0.85**
- 无退化样本 ≥90 分;四类退化全满 ≤25 分(重拓档)
- 墨色浓淡(风格)变化时综合分波动 ≤8,不影响排名
- 同退化等级跨种子标准差 <7,排序稳定
- GL/CPU 归约 parity、Spearman 数学性质、Otsu/Sobel/形态学算子正确性

## 性能

- 逐像素的墨色统计、盒式模糊、Sobel 字口锐度、tophat 都在 **WebGL2 着色器**里并行;
- 大图按 2048 tile(带 4px halo)分块,规避单纹理尺寸限制;
- CPU 管线是确定性参考实现,54MP 约 9 秒;生产路径走 GL,基准页可实测 3 秒预算。
